# IMPLEMENTATION CALENDAR
*For the founder and BDM — activating the system from paper to reality.*

---

## Week 1 — Publish

**Day 1–2:**
- [ ] Move all documents to a single shared location accessible to every employee
  - Recommended: A `/playbooks` folder in the company Google Drive or Notion workspace
  - Every document named clearly and consistently
  - Organised exactly as this index shows (Tier 1 through Tier 6)

- [ ] Every current employee receives the link and is asked to read:
  - Culture Deck (for context)
  - Their role's checklist
  - The Escalation SOP

**Day 3–5:**
- [ ] BDM reviews all 18 documents and flags any gaps specific to Grekam
- [ ] Founder reviews the Culture Deck — is this exactly what we want to say?
- [ ] KPI dashboard is reviewed — what targets do we set for this month?

---

## Week 2 — Set the Cadence

**Sales:**
- [ ] Every salesperson submits a daily report from Day 1 of Week 2
- [ ] BDM reviews all pipelines every Friday using the health check template
- [ ] Monday pipeline report to management starting this week

**Delivery:**
- [ ] Every project in Grekam OS is updated to current status by end of Week 2
- [ ] Project health dashboard reviewed every Monday morning

**Management:**
- [ ] Management report template prepared for end of this month
- [ ] KPI targets confirmed per role for the next 30 days

---

## Month 1 — First Full Onboarding

**The next person hired** is onboarded entirely using these documents.

Track every gap that required a verbal explanation by the founder or manager.

For each gap:
1. Identify which document should have covered it
2. Update that document
3. If no document covers it — write one

The goal: by the end of the first new hire's onboarding, zero verbal explanations were needed that could have been in the system.

---

## Month 2 — Measure and Improve

At the end of Month 2, review:

- Did the daily/weekly report cadence actually happen? If not — why?
- Did the new hire use the documents or depend on verbal guidance?
- Which documents were most referred to?
- Which documents were never opened?
- What is missing?

Update the index and the documents accordingly.

The system is version 1.0. It improves through use.

# THE RULE ABOUT THIS SYSTEM

This system is only as good as the last time it was used and updated.

Documents that are written and forgotten are worse than documents that were never written — because they create false confidence.

**Assign:** Every document has an owner.
**Use:** Every process in this system is followed, not referenced occasionally.
**Update:** When reality changes, the document changes within 48 hours.
**Audit:** Once per quarter, the BDM reviews every document for accuracy.
