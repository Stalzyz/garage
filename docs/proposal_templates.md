# Grekam — Proposal Templates
### Version 1.0 | Sales Team Reference | August 2026

---

> A proposal is not a price list.
> It is a document that answers one question:
> **"Why should I choose Grekam?"**
>
> Write it for the customer, not for yourself.

---

# PROPOSAL RULES

1. **Send every proposal as a PDF.** Not a screenshot, not a WhatsApp message, not a verbal quote.
2. **Personalise the first paragraph.** Never send a generic template without editing the opening.
3. **Reference the conversation.** The customer should recognise their own problem in your proposal.
4. **Keep it short.** Maximum 3 pages for a standard proposal. If it's longer, it's unclear.
5. **State the next step explicitly.** The customer should know exactly what to do if they want to proceed.
6. **Get verbal alignment before sending.** Proposals that land with no prior discussion rarely convert.

# PROPOSAL DO'S AND DON'TS

| ✅ Do | ❌ Don't |
|---|---|
| Reference the customer's specific problem | Use generic copy for every proposal |
| State exactly what is included | Leave scope ambiguous |
| State what is NOT included | Assume the customer understands the limits |
| Give a clear payment milestone structure | State just "50% upfront" without context |
| Include a valid until date | Leave the proposal open-ended |
| Follow up 2 days after sending | Wait for the client to come back |
| Get verbal alignment before sending | Send a cold proposal as your first contact |
